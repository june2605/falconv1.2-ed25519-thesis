HybridSign 0.1.0
Windows research app for PDF signatures with Ed25519 and Falcon-512.

Setup installs HybridSign for the current Windows user. Open it from the
Start Menu or choose to add a Desktop shortcut. Before installing or
uninstalling, let any signing finish and close HybridSign.

You need Windows x64, Microsoft Edge WebView2 Evergreen Runtime 111 or later
and Microsoft .NET Framework 4.6.2 or later. Get missing runtimes from
Microsoft before running Setup. Setup and the application are unsigned.

Choose a dedicated app folder on a local drive. Store your encrypted vaults
and PDFs in a separate user-controlled folder on a fixed local NTFS drive.
Uninstall removes the installed app and its shortcuts. Your vaults and
PDFs kept in separate storage stay in place.

Verification checks both signatures with the public keys you select.
Signer identity and signing time require separate evidence. HybridSign
uses a custom signature format. CMS, PAdES and FIPS 206 conformance have
not been established.
